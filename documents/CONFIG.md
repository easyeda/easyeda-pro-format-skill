# CONFIG

> 返回 [SKILL.md](../SKILL.md) 入口文档

## 领域概述

CONFIG 是嘉立创 EDA 格式中的工程设置文档类型，用于存储整个项目的全局配置信息。包含通用设置（如是否允许工程库重名、默认网络名、导线多网络、网络标识跨层连接等原理图相关设置）、显示方式、图页位置等选项。CONFIG 文件中的 defaultSheet 字段指定默认的原理图页面。
