# EBothEndShape

> 返回 [REFERENCE 类型索引](../../documents/REFERENCE.md)

## 定义

折线两端的点的形状

## 取值

| 取值 | 类型 | 说明 |
|------|------|------|
| `NONE` | string | 无 |
| `ARROW` | string | 箭头 |
| `SOLID_ARROW` | string | 实心箭头 |
| `TAIL` | string | 尾巴 |
| `SOLID_TAIL` | string | 燕尾箭头 |
| `CIRCLE` | string | 圆形 |
| `SQUARE` | string | 方形 |
| `RHOMBUS` | string | 菱形 |
