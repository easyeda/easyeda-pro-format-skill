# ERoutingConner

> 返回 [REFERENCE 类型索引](../../documents/REFERENCE.md)

## 定义

布线拐角模式

## 取值

| 取值 | 类型 | 说明 |
|------|------|------|
| `L45` | string | 线条 45 度 |
| `L90` | string | 线条 90 度 |
| `L` | string | 线条自由角度 |
| `R45` | string | 圆弧 45 度 |
| `R90` | string | 圆弧 90 度 |
| `R` | string | 圆弧自由角度 |
