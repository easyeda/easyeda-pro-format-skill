## 定义

移除未使用焊盘的范围

## 取值

| 取值 | 类型 | 说明 |
|------|------|------|
| `ALL` | string | 所有 |
| `PAD` | string | 仅焊盘 |
| `VIA` | string | 仅过孔 |
