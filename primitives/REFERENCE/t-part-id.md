# TPartId

> 返回 [REFERENCE 类型索引](../../documents/REFERENCE.md)

## 定义

PART id —— 指向**某条 `PART` 行**的图元 id

⚠️ **本类型不是格式图元**（本目录都是这类 id 说明），它**不占任何一行数据**。

⚠️ 它**不是** uuid，也**不是**符号文档的 uuid —— 是**符号文档内部**某条 `PART` 行的 `id`。

## 同一个字段，两种用法（**取决于本文档是图页还是符号页**）

- **图页（SCH_PAGE）里的元件**：本字段指向**别的文档**——
  要先去该元件 `key:"Symbol"` 属性所标识的那个**符号文档**里，才能找到对应那条 `PART` 行。
  图页文档本身**没有 `PART` 行**。
- **符号页（SYMBOL）自身**：本字段就是**本文档里的**那条 `PART` 行 —— 不需要跨文档找。

所以判断「要不要跨文档」的依据是**本文档的类型**，不是字段值本身。
