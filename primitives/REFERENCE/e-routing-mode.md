# ERoutingMode

> 返回 [REFERENCE 类型索引](../../documents/REFERENCE.md)

## 定义

布线模式

## 取值

| 取值 | 类型 | 说明 |
|------|------|------|
| `NONE` | string | 无 |
| `PUSH` | string | 推挤 |
| `SURROUND` | string | 环绕 |
| `OBSTRUCT` | string | 阻挡 |
| `SURROUND&PUSH` | string | 环绕并推挤 |
