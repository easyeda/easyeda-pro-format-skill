# ESchDataType

> 返回 [REFERENCE 类型索引](../../documents/REFERENCE.md)

## 定义

原理图数据类型枚举

## 取值

| 取值 | 类型 | 说明 |
|------|------|------|
| `META` | string | 基本配置 |
| `CANVAS` | string | 画布配置 |
| `GROUP` | string | 分组控制 |
| `ATTR` | string | 属性 |
| `LINE` | string | (导线/总线)线段（原理图专有） |
| `WIRE` | string | 导线组 （原理图专有） |
| `BUS` | string | 总线组（原理图专有） |
| `TEXT` | string | 文本 |
| `POLY` | string | 多边形 |
| `CIRCLE` | string | 圆 |
| `ARC` | string | 圆弧 |
| `BUSENTRY` | string | 总线接入标识 |
| `RECT` | string | 矩形 |
| `MASK_REGION` | string | 屏蔽区域 |
| `PIN` | string | 标号（对应 TSchPin；显示名沿用客户端中文口径「标号」） |
| `OBJ` | string | 二进制内嵌对象 |
| `COMPONENT` | string | 元件（原理图专有） |
| `PART` | string | 部件（符号专有） |
| `ELLIPSE` | string | 椭圆 |
| `BEZIER` | string | 贝塞尔 |
| `TABLE` | string | 表格 |
| `ELE_PLACEHOLDER` | string | 占位符 |
| `NG_SETTING` | string | 仿真图页 - 仿真设置 |
