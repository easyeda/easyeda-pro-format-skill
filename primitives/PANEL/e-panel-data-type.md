# EPanelDataType

> 返回 [PANEL 图元索引](../../documents/PANEL.md)

## 定义

数据类型

## 取值

| 取值 | 类型 | 说明 |
|------|------|------|
| `META` | string | 基本信息 |
| `CANVAS` | string | 画布配置 |
| `GROUP` | string | 分组控制 |
| `POLY` | string | 多边形 |
| `STRING` | string | 文字 |
| `AUXLINE` | string | 辅助线 |
| `DIMENSION` | string | 尺寸工具集 |
| `ELE_PLACEHOLDER` | string | 占位符 |
